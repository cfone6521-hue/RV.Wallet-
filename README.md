# 🟢 RV Web3 — Painel Blockchain

> Painel Web3 para consulta de saldos, transações e conexão de carteiras digitais.

---

## 🚀 Funcionalidades

- ✅ Conexão com carteira Web3 (MetaMask, WalletConnect)
- ✅ Consulta de saldos em tempo real
- ✅ Histórico de transações
- ✅ Suporte a Ethereum Mainnet
- ✅ Interface responsiva e moderna

---

## 🛠️ Tecnologias

- **Frontend:** HTML, CSS, JavaScript
- **Servidor:** Node.js + Express
- **Integração Web3:** Ethers.js / Web3.js
- **Estilização:** CSS moderno com design dark theme
